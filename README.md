# Modélisation des systèmes biologiques - Projet R

## Description
Ce dépôt contient les éléments du projet réalisé dans le cadre du cours de **Bio-informatique Système Dynamique** en Licence Double Diplôme Biologie-Informatique. L'objectif est d'analyser les profils d'expression de 10 gènes mesurés dans trois échantillons différents, et de construire un réseau de coexpression basé sur ces données.

## Contenu du dépôt
- **`expression_data.csv`** : Fichier contenant les données d'expression des 10 gènes dans trois échantillons.
- **`analysis.R`** : Script R utilisé pour :
  - Tracer les profils d'expression.
  - Calculer les coefficients de corrélation.
  - Construire le réseau de coexpression.
- **`rapport.pdf`** : Rapport final contenant les analyses, figures et réponses aux questions.
